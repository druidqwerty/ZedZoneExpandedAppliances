# ZED ZONE: Расширенные переносные приборы

**Специально по заказу для пользователя: `6VaN4!K96`**

[![Поддержать разработку](https://raw.githubusercontent.com/druidqwerty/ZedZoneExpandedAppliances/e6c552329066c1bc794627cdbe63806fb2a3204f/docs/banner.png)](https://boosty.to/lrgpp)

[English](README.md) · [简体中文](README_CN.md)

Кодовый мод BepInEx 6 (IL2CPP) для **ZED ZONE** (`1.0.20`), расширяющий вместимость трёх переносных приборов-контейнеров до **`20×26` (520 ячеек)** по умолчанию — с безопасным автоапгрейдом старых сохранений и отдельной настройкой каждого прибора.

## Что расширено

| Прибор | ID предмета | Ваниль | По умолчанию в моде |
|---|---|---|---|
| **Переносной мини-холодильник** | `1063` | `8×6` (48 ячеек) | **`20×26`** (520 ячеек) |
| **Переносная зарядная станция** | `1066` | `8×4` (32 ячейки) | **`20×26`** (520 ячеек) |
| **Солнечная зарядная станция** | `1067` | `8×4` (32 ячейки) | **`20×26`** (520 ячеек) |

## Возможности

- **Безопасный апгрейд старых сейвов:** уже имеющиеся приборы в рюкзаке, ящиках, багажниках и у напарников автоматически расширяются при загрузке и открытии без потери и сдвига вещей.
- **Ванильные механики сохранены:** охлаждение, зарядка от автоаккумулятора и солнца, фильтр батарей и автосортировка работают по всей сетке.
- **Конфиг (`BepInEx/config/com.druid.zedzone.expandedappliances.cfg`):** отдельное включение и настройка ширины (`8–40`) и высоты (`до 100`) для каждого прибора.
- **Защита от потери лута:** по умолчанию (`AllowSafeShrink = false`) контейнеры только расширяются и никогда не сжимаются.

## Установка

1. Установите сторонний [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258) и один раз запустите `install.cmd`.
2. Подпишитесь в Steam Workshop или распакуйте `ExpandedAppliances/` из [релизов GitHub](https://github.com/druidqwerty/ZedZoneExpandedAppliances/releases) в `<ZED ZONE>\Mods\ExpandedAppliances\`.
