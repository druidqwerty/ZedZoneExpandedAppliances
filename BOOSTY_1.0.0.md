## ZED ZONE: Expanded Portable Appliances (`v1.0.0`)

Expands the container grid capacity of the three portable storage appliances in **ZED ZONE** to a spacious **`20×26` (520 slots)** grid — with automatic safe upgrades for existing saves and full per-appliance size configuration:

- **Portable Mini Fridge (`ID 1063`):** vanilla `8×6` (48 slots) → **`20×26`** (520 slots).
- **Portable Charger Box (`ID 1066`):** vanilla `8×4` (32 slots) → **`20×26`** (520 slots).
- **Solar Charger Box (`ID 1067`):** vanilla `8×4` (32 slots) → **`20×26`** (520 slots).
- **Safe Existing Save Upgrade:** Already-owned appliances in backpacks, chests, vehicle trunks, or companion inventories automatically expand without losing or shifting stored items.
- **Vanilla Mechanics & Full Config:** Refrigeration, solar/car-battery charging, battery-only charger filters, and auto-sorting work seamlessly. Customize each appliance's width (`8–40`) and height (`up to 100`) in `BepInEx/config/com.druid.zedzone.expandedappliances.cfg` (with safe shrink protection enabled by default).

Requires third-party [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader is not a mod by druidqwerty.

## ZED ZONE: Расширенные переносные приборы (`v1.0.0`)

Расширяет вместимость трёх переносных приборов-контейнеров в **ZED ZONE** до просторной сетки **`20×26` (520 ячеек)** — с безопасным автоапгрейдом старых сохранений и отдельной настройкой размера для каждого прибора:

- **Переносной мини-холодильник (`ID 1063`):** ваниль `8×6` (48 ячеек) → **`20×26`** (520 ячеек).
- **Переносная зарядная станция (`ID 1066`):** ваниль `8×4` (32 ячейки) → **`20×26`** (520 ячеек).
- **Солнечная зарядная станция (`ID 1067`):** ваниль `8×4` (32 ячейки) → **`20×26`** (520 ячеек).
- **Безопасный апгрейд старых сейвов:** уже имеющиеся приборы в рюкзаке, ящиках, багажниках и у напарников автоматически расширяются без потери и сдвига вещей.
- **Ванильные механики и гибкий конфиг:** охлаждение, зарядка от автоаккумулятора и солнца, фильтр батарей и автосортировка работают по всей сетке. Ширина (`8–40`) и высота (`до 100`) каждого прибора настраиваются отдельно в `BepInEx/config/com.druid.zedzone.expandedappliances.cfg` (защита от случайного сжатия включена по умолчанию).

Требуется сторонний [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader не является модом druidqwerty.
