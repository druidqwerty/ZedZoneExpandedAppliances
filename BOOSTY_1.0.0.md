## ZED ZONE: Expanded Portable Appliances (`v1.1.0`)

Expands the container grid capacity of the three portable storage appliances and the stationary base **Battery Charger Bench** in **ZED ZONE** to a spacious **`20×26` (520 slots)** grid — with automatic safe upgrades for existing saves, full expanded-grid charging support, and per-appliance size configuration:

- **Portable Mini Fridge (`ID 1063`):** vanilla `8×6` (48 slots) → **`20×26`** (520 slots).
- **Portable Charger Box (`ID 1066`):** vanilla `8×4` (32 slots) → **`20×26`** (520 slots).
- **Solar Charger Box (`ID 1067`):** vanilla `8×4` (32 slots) → **`20×26`** (520 slots).
- **Stationary Battery Charger Bench (`ID 126`, added in `v1.1.0`):** vanilla `4×4` (16 slots) → **`20×26`** (520 slots), with full charging across all 520 slots and LED indicator sync.
- **Safe Existing Save Upgrade:** Already-owned portable appliances (in backpacks, chests, vehicle trunks, or companion inventories) and already-built stationary charging benches automatically expand without losing or shifting stored items.
- **Vanilla Mechanics & Full Config:** Refrigeration, solar/car-battery/grid charging, battery-only charger filters, and auto-sorting work seamlessly. Customize each appliance's width (`4–40` / `8–40`) and height (`up to 100`) in `BepInEx/config/com.druid.zedzone.expandedappliances.cfg` (with safe shrink protection enabled by default).

Requires third-party [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader is not a mod by druidqwerty.

## ZED ZONE: Расширенные переносные приборы (`v1.1.0`)

Расширяет вместимость трёх переносных приборов-контейнеров и стационарной зарядной станции базы в **ZED ZONE** до просторной сетки **`20×26` (520 ячеек)** — с безопасным автоапгрейдом старых сохранений, полноценной зарядкой по всей сетке и отдельной настройкой размера для каждого прибора:

- **Переносной мини-холодильник (`ID 1063`):** ваниль `8×6` (48 ячеек) → **`20×26`** (520 ячеек).
- **Переносная зарядная станция (`ID 1066`):** ваниль `8×4` (32 ячейки) → **`20×26`** (520 ячеек).
- **Солнечная зарядная станция (`ID 1067`):** ваниль `8×4` (32 ячейки) → **`20×26`** (520 ячеек).
- **Стационарная зарядная станция (`ID 126`, добавлено в `v1.1.0`):** ваниль `4×4` (16 ячеек) → **`20×26`** (520 ячеек), с полноценной зарядкой батарей в любых ячейках и корректной индикацией светодиодов.
- **Безопасный апгрейд старых сейвов:** уже имеющиеся переносные приборы (в рюкзаке, ящиках, багажниках и у напарников) и уже построенные стационарные зарядные станции автоматически расширяются без потери и сдвига вещей.
- **Ванильные механики и гибкий конфиг:** охлаждение, зарядка от автоаккумулятора, солнца и сети базы, фильтр батарей и автосортировка работают по всей сетке. Ширина (`4–40` / `8–40`) и высота (`до 100`) каждого прибора настраиваются отдельно в `BepInEx/config/com.druid.zedzone.expandedappliances.cfg` (защита от случайного сжатия включена по умолчанию).

Требуется сторонний [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader не является модом druidqwerty.
