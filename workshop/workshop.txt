description=[h2]What It Expands[/h2]
description=[list][*]Portable Mini Fridge (ID 1063): vanilla 8x6 (48 slots) -> 20x26 (520 slots).[*]Portable Charger Box (ID 1066): vanilla 8x4 (32 slots) -> 20x26 (520 slots).[*]Solar Charger Box (ID 1067): vanilla 8x4 (32 slots) -> 20x26 (520 slots).[/list]
description=[h2]Key Features[/h2]
description=[list][*]Safe Existing Save Upgrade: appliances you already own in backpacks, chests, vehicle trunks, or companion inventories automatically expand to 20x26 when loaded or opened — without losing or shifting any stored items.[*]Vanilla Mechanics Preserved: refrigeration, solar/car-battery charging, battery-only slot rules on chargers, and auto-sorting all work seamlessly across the entire expanded grid.[*]Fully Configurable (BepInEx/config/com.druid.zedzone.expandedappliances.cfg): toggle each appliance individually and set any custom width (8-40) and height (up to 100).[*]Safe Shrink Protection: by default (AllowSafeShrink = false), existing containers only expand and never shrink. Even if enabled, containers never shrink below the coordinates of stored items.[/list]
